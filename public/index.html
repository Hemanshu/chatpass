ChatPass

Hand a secret to an AI agent without pasting it into the chat. It's encrypted in your browser; the server only holds ciphertext, briefly, and deletes it on first retrieval.

Waiting for retrieval…

The prompt contains the decryption key, so treat it like the secret until it has been retrieved. Once it's retrieved or expired, the prompt is useless.

How it works
  1. Your browser generates a random 256-bit AES-GCM key and encrypts the secret locally.
  2. Only the ciphertext is uploaded. The server keeps it in memory (never on disk) until it expires or is retrieved.
  3. The prompt gives the agent a one-line script that POSTs to the reveal URL, decrypts locally with the key, and saves the result to ~/.chatpass/NAME with mode 600.
  4. The server deletes the ciphertext on retrieval. The key never touches the server, and the ciphertext never appears in the chat.
